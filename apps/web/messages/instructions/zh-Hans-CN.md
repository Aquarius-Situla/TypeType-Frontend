# TypeType 简体中文 (zh-Hans-CN) 本地化工程风格指南

本规范为 TypeType 客户端界面的简体中文本地化提供工程化标准，适用于 Weblate 协同翻译、Pull Request 贡献及人工审校流程。贡献者与审校人员应严格遵循本指南以保持界面文案的准确性、专业性与一致性。

---

## 1. 品牌资产与专有名词 (Brand Assets & Terminology)

### 1.1 专有名词保留原文
所有第三方平台、外部协议及专有技术名词一律保留官方拉丁字母原名，严禁音译、意译或非官方简称。

- 正确：`YouTube`、`BiliBili`、`NicoNico`、`SponsorBlock`、`Weblate`、`Lemmy`、`DASH`、`HLS`、`RSS`、`Token`、`API`、`JSON`、`Chromium`
- 错误：油管、哔哩哔哩、B站、Nico动画、双子座、赞助屏蔽

### 1.2 大小写规范
大小写必须与服务商官方注册商标完全一致。
- 正确：`BiliBili`、`YouTube`、`TypeType`
- 错误：`bilibili`、`Bilibili`、`Youtube`、`typetype`

---

## 2. 排版格式与中西文混排 (Typography & Spacing)

### 2.1 盘古之白 (CJK & Latin Spacing)
中文字符（汉字）与西文字符（拉丁字母、阿拉伯数字、英文单位及专用符号）之间，必须保留一个半角空格。

- 格式规则：`[汉字] [西文/数字] [汉字]`
- 正确：`BiliBili 缓冲`、`1× 倍速`、`等待 15 分钟`、`连接 TV 端`
- 错误：`BiliBili缓冲`、`1×倍速`、`等待15分钟`
- 全角标点例外（全角标点符号与中西文字符之间不留空格）：
  - 正确：`（每隔几分钟自动刷新）`
  - 错误：`（ 每隔几分钟自动刷新 ）`、`（每隔几分钟自动刷新） `

### 2.2 标点符号抑制与界面断句 (Punctuation Suppression)
遵循现代 GUI 界面交互规范，降低视觉杂讯：

1. **末尾标点省略**：
   - 标签（Label）、按钮（Button）、选项提示（Hint）、单行/多行辅助说明（Description）的**句末一律省略句号（`。`）**。
   - 正确：`在有限速或按流量计费的网络下更省流量`
   - 错误：`在有限速或按流量计费的网络下更省流量。`
2. **复合说明中的停顿与全角逗号规范**：
   - 界面说明文案（Description）若包含多重逻辑从句，统一使用**中文全角逗号（`，`）**断句，避免使用句号切断语流。
   - **严格禁止使用英文半角逗号（`,`）**作为中文字句的分隔符。
   - 正确（全角逗号）：`BiliBili 视频提前预加载的时长，会随播放倍速增加，让高倍速播放依然保持流畅`
   - 错误（误用半角逗号）：`BiliBili 视频提前预加载的时长, 会随播放倍速增加, 让高倍速播放依然保持流畅`
   - 错误（误用句号）：`BiliBili 视频提前预加载的时长。会随播放速度增加，让快速播放保持流畅。`

## 3. 并列选项对齐与词义对仗 (Symmetry & Precision)

同一功能层级下的枚举分档、并列选项，应保持字数、词性与表达维度的严谨对称。

- **三档调节示例**：
  - 正确（双字对称）：`省流` / `标准` / `较大`
  - 错误（长短不一）：`省流` / `标准` / `大`
- **状态表述精准度**：
  - 正确（简练严谨）：`视频服务暂不可用，请稍后再试`
  - 错误（冗余虚词）：`视频服务暂时不可用，请稍后再试`

## 4. 语境消除与歧义防范 (Contextual Disambiguation)

在缺乏运行时渲染上下文的键值翻译中，必须通过源码调用点反查实际场景，严禁脱离 UI 妄加直译：

| 英文 Key / 片段 | 常见误译（脱离语境） | 规范翻译（符合真实 UI） | 语境判定说明 |
| :--- | :--- | :--- | :--- |
| `ui_search_history_2` | 搜索记录... | **搜索观看历史...** | 此处为“观看历史”页面的过滤检索框，若译为“搜索记录”将与历史搜索词产生严重歧义 |
| `ui_youtube_rejected_stored_session` | ...请重新生成验证码。 | **YouTube 拒绝了存储的授权，请重新连接** | 原文中的 `code` 属设备授权配对码，在中文中若提“验证码”会使用户下意识联想为短信 OTP / 图形验证码 |
| `settings_bilibili_buffer_saver_hint` | 在慢速或流量受限的网络下... | **在有限速或按流量计费的网络下更省流量** | 明确网络约束机制（QoS 限速 / 按量计费），而非模糊的“慢速” |
| `ui_verified_personal` | 个人认证 | **创作者认证** | 视频平台创作者认证体系的标准行业术语 |

## 5. 本地化生命周期与质量分级机制 (Localization Lifecycle)

为防止大语言模型（LLM）初稿的机械生硬直接流入生产环境，社区协同推行两级状态管理：

```
[源文本 en.json 更新]
        │
        ▼
[机器/AI 初稿 (Machine Draft)] ────► 仅供开发阶段 Key Coverage 占位，标注未审核
        │
        ▼ 人工语境审校 (Human In-Context Review)
[正式审校定稿 (Verified Release)] ──► 符合本指南规范，合入 dev 主分支
```

- **待复核状态（Unverified / Draft）**：由自动化工具或 AI 批量填充的词条，未结合运行时渲染复核，允许社区提交修改。
- **已校对状态（Human Verified）**：经母语工程人员验证、符合标点抑制、语境准确、品牌专名要求的词条。
