# TypeType 简体中文本地化风格指南

本指南规定 TypeType 客户端界面简体中文文案的写法，适用于 Weblate 协同翻译、Pull Request 贡献和人工审校。

- 规则编号（如 R2.3）可在 PR 和审校评论中直接引用。
- 高频词汇的统一译法见 [术语表](./zh-Hans-CN.glossary.csv)，本文只写判定原则。

---

## 1. 品牌与专有名词

### R1.1 保留原文

第三方平台、外部协议和专有技术名词保留官方的拉丁字母原名，不意译、不音译，也不用中文俗称。

- 正确：`YouTube`、`BiliBili`、`NicoNico`、`Gemini`、`SponsorBlock`、`Weblate`、`Lemmy`、`DASH`、`HLS`、`RSS`、`Token`、`API`、`JSON`、`Chromium`
- 错误：油管、哔哩哔哩、B站、Nico动画、双子座、赞助屏蔽

### R1.2 拼写与大小写

本项目约定统一使用驼峰拼写，避免全小写的写法在句中不易辨认。

- 正确：`BiliBili`、`NicoNico`、`YouTube`、`TypeType`
- 错误：`bilibili`、`niconico`、`Youtube`、`typetype`

## 2. 排版

### R2.1 中西文空格

中文与西文（拉丁字母、阿拉伯数字、英文单位、专用符号）之间保留一个半角空格。全角标点与中西文之间不留空格。

- 正确：`BiliBili 缓冲`、`1× 倍速`、`等待 15 分钟`、`连接 TV 端`、`（每隔几分钟自动刷新）`
- 错误：`BiliBili缓冲`、`1×倍速`、`等待15分钟`、`（ 每隔几分钟自动刷新 ）`、`（每隔几分钟自动刷新） `

### R2.2 句末标点

标签、按钮、选项提示和辅助说明的句末不加句号。

- 正确：`在有限速或按流量计费的网络下更省流量`
- 错误：`在有限速或按流量计费的网络下更省流量。`

### R2.3 逗号与停顿

辅助说明有多个分句时，用全角逗号 `，` 断句，不用半角逗号 `,`，也不用句号把句子切开。

- 正确：`BiliBili 视频提前预加载的时长，会随播放倍速增加，让高倍速播放依然保持流畅`
- 错误（半角逗号）：`BiliBili 视频提前预加载的时长, 会随播放倍速增加, 让高倍速播放依然保持流畅`
- 错误（句号断句）：`BiliBili 视频提前预加载的时长。会随播放速度增加，让快速播放保持流畅。`

### R2.4 引号

中文引用、强调项和实体名称用全角双引号 `“”`，不用半角引号 `""` 或直角引号 `「」`。全角引号与前后的中文、西文、插值变量（如 `{name}`）之间不加空格。

- 正确：`在“设置”中修改`、`确定删除播放列表“{name}”吗？`、`支持“YouTube”及其他平台`
- 错误（多余空格）：`在 “设置” 中修改`、`确定删除 “{name}” 吗？`
- 错误（引号类型）：`在"设置"中修改`、`在「设置」中修改`

### R2.5 括号

括号有两种用法，按括号里的内容选择。

| 用法 | 括号 | 适用内容 | 正确 | 错误 |
| :--- | :--- | :--- | :--- | :--- |
| 补充说明 | 全角 `（）` | 括号内含中文的补充说明、单位注解、选项解释 | `添加时间（最新）`、`超时限制（毫秒）`、`画质（自动）` | `添加时间(最新)`、`添加时间 (最新)` |
| 计数与西文附注 | 半角 `()` | 紧跟功能名词的计数插值、西文缩写、数值标签 | `全部频道 ({count})`、`播放列表 ({count})`、`知识共享 (CC)` | `全部频道（{count}）` |

半角括号与前面的中文之间按 R2.1 保留空格。

### R2.6 确认类弹窗

部分确认文案在英文源文中把疑问和警告写在同一个词条里，例如 `Delete "{name}"? This cannot be undone.`。词条拆分为标题和正文之前，按以下规则翻译：先交代风险，再以疑问句收尾。

- 正确：`此操作无法撤销，确定删除播放列表“{name}”吗？`
- 错误（问号在句中，后半句没有标点）：`确定删除播放列表“{name}”吗？此操作无法撤销`
- 错误（问号移到句末，警告变成反问）：`确定删除播放列表“{name}”，此操作无法撤销？`

> [!NOTE]
> 这是过渡规则，词条拆分后可重新评估。

## 3. 文案精炼

### R3.1 并列项对称

同一功能下的并列选项，字数、词性和表达角度应保持一致。

- 正确：`省流` / `标准` / `较大`
- 错误：`省流` / `标准` / `大`

### R3.2 避免冗余的时间副词

状态提示和错误反馈中，没有实际指引作用的“暂时”应去掉。

- 正确：`视频服务暂不可用，请稍后再试`、`无法清除搜索记录，请稍后再试`
- 错误：`视频服务暂时不可用，请稍后再试`、`暂时无法清除搜索记录，请稍后再试`

## 4. 动词用法

英文界面常常混用动作动词。翻译时按操作的实际后果和对象的性质选词，不逐字直译。

### R4.1 删除与移除

英文 `Remove` 语气较轻，而“移除”带有“移到别处”的意味，容易让用户疑惑内容去了哪里。按下表判断：

| 情形 | 译法 | 判断依据 | 示例 |
| :--- | :--- | :--- | :--- |
| 数据被销毁 | 删除 | 对象从系统或个人账户中抹除 | `删除视频`（`Remove video`）、`从历史记录中删除`（`Remove from history`）；独立按钮 `删除`（`Remove`） |
| 仅解除归属 | 从……中移除 | 有明确的容器（`from group`、`from favorites`、`from watch later`），对象本身仍然存在 | `从分组中移除`（`Remove from group`）、`从收藏夹中移除`（`Remove from Favorites`） |
| 取消保存他人的内容 | 取消保存 | 保存的是第三方播放列表，避免用户以为原作者的列表被删除 | `取消保存播放列表`（`Remove saved playlist`） |

- 历史记录条目属于账户数据，删除后即消失，所以用“删除”；收藏夹里的视频仍在平台上，只是移出了收藏夹，所以用“移除”。
- 错误：`移除视频`；把“从分组中移除”译成“删除频道”，会让用户以为取消了订阅。

### R4.2 清空与清除

| 译法 | 对象 | 示例 |
| :--- | :--- | :--- |
| 清空 | 容器、列表、筛选条件、选区，操作后变为空 | `清空全部`（`Clear all`）、`清空筛选`（`Clear filters`）、`清空已选`（`Clear selection`）、`清空播放列表`（`Clear playlist`） |
| 清除 | 行为痕迹、缓存、历史记录条目、对象属性，抹去数据本身 | `清除观看记录`（`Clear watch history`）、`清除搜索记录`（`Clear search history`）、`清除缓存`（`Clear cache`）、`清除头像`（`Clear avatar`） |

错误：`清空观看记录`、`清空搜索记录`、`清空缓存`

### R4.3 常用动作动词

| 英文 | 译法 | 适用场景 |
| :--- | :--- | :--- |
| `Cancel` | 取消 | 撤回尚未提交的等待状态或操作流程，如取消自动播放、取消下载，以及弹窗中的放弃按钮 |
| `Dismiss` | 忽略 | 关闭不阻断操作的横幅、气泡和轻量通知，不涉及业务状态回滚 |
| `Revoke` | 撤销 | 使安全凭证、外部授权、API 密钥、私密订阅链接失效，如撤销密钥、撤销 RSS 订阅链接 |
| `Undo` | 撤回 | 逆转刚发生并已生效的操作，如操作成功提示中的“撤回”按钮；与 `Revoke` 的“撤销授权”区分 |
| `Retry` | 重试 | 网络失败或出现异常后，再次发起请求 |

## 5. 术语

本节说明“历史”与“记录”的取舍。其他词条见 [术语表](./zh-Hans-CN.glossary.csv)。

### R5.1 “历史”与“记录”

1. **顶级导航**：为与“首页”“订阅”等双字入口对齐，侧边栏和底栏的 `History` 译为“历史”。空间不受限的常规文案译为“历史记录”。
2. **账户级总称**：泛指整个账户的行为数据时，用“历史记录”。
   - 正确：`导入你的 YouTube 历史记录`（`Import your YouTube history`）、`不会删除你的历史记录`（`your history is not deleted`）
3. **具体清单**：针对具体操作的清单和数据项，用“记录”，不用“历史”。
   - 正确：`观看记录`（`Watch history`）、`搜索记录`（`Search history`）
   - 错误：`观看历史`、`搜索历史`
4. **算法偏好中的分类**：按具体清单处理，沿用“记录”。对象是视频和 Shorts，写作“播放记录”，不写“历史”，避免读成“视频的发展历史”。
   - 正确：`视频播放记录`（`Video history`）、`Shorts 播放记录`（`Shorts history`）
   - 错误：`视频历史`、`Shorts 历史`

### R5.2 动词与名词同字

动词“记录”“跟踪”遇到名词“观看记录”时，避免写成“记录观看记录”。保留名词，换一个动词。

- 正确：`Watch history tracking` 开关译为 `保存观看记录` 或 `跟踪观看记录`
- 错误：`记录观看记录`

## 6. 审校流程

词条分两种状态，避免机器初稿直接进入正式版本。

- **草稿（Draft）**：由自动化工具或 AI 批量填充，未对照界面实际显示复核，仅用于覆盖词条，允许社区修改。
- **已校对（Verified）**：由母语审校人员对照界面审核，符合本指南的标点、语境和专有名词要求。

流程：`en.json` 更新 → 草稿 → 人工对照界面审校 → 已校对，合入 dev 主分支。
